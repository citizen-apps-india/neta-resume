What makes it hard to use

  1. 1
    Two caveats before any contentA grey box and a legend line both explain sourcing before the table.
  2. 2
    Key status badge easy to miss'Paraphrased from news reports' sits low, same size as the caveats above it.
  3. 3
    Quote vs paraphrase: only tiny printA one-line legend carries a distinction the table itself doesn't show.
  4. 4
    No highlight on what's newStrikethrough and italics don't show which words were actually added.
  5. 5
    'About this text' isn't collapsedThe long sourcing note is fully open, pushing real content down.
  6. 6
    A dense legal title, no summaryNothing states the change itself before the reader reaches the table.
